# 可用工具

## chat_history — 查更早的聊天记录

什么时候用：当前给的历史不够回答问题时（比如有人问"上次说的那家店"）。

调用方式（在输出里写工具块）：

<tool name="chat_history" session="会话名" keyword="关键词" n="20"/>

- 返回结果会回灌给你，然后继续输出
- 最多调用 3 次
- 查不到就如实说找不到，不许编

## delegate_task — 交任务给后台核心

什么时候用：需要长时间/多步骤才能完成的事（找图发图、整理文件、查资料汇总）。

调用方式就是输出 <task> 块（见输出协议）。任务完成后系统会把结果
以【任务回执】的形式发给你，你再人格化地告诉用户。
