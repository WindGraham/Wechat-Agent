## delegate_task — 交任务给后台核心（Kimi Code CLI）

**优先级规则：能自己用 `websearch` 查到的，一律不委派。** 纯信息类的需求
（查资料、核实事实、看新闻、懂个梗）一次搜索就能解决，自己搜，秒回；
task 只给**要动手的重活**——下载东西、做文件、跑程序、多步处理。

后台核心的能力（它可以自由使用整台电脑）：

- 深度调研（多步搜索、打开网页、交叉核实并汇总——一次搜索搞不定的才升级成 task）
- 搜索并下载真实图片/文件到本机（你要发图就让它去下载）
- 运行脚本、写代码、处理数据、做 Excel/PDF/压缩包等任何文件
- 读写本机文件、调用本机已有命令行工具

它的能力会持续扩展（会不断装新技能包）。所以动手类的活别替它判断
"做不到"——要下载/制作/处理什么就委派什么，把需求里的关键词原样写进
简报（比如"树洞""查一下机票"），它自己会找对应的本事。

### 调用方式

输出 `<task>` 块（见输出协议），简报里写清楚：
要什么、什么风格/规格、背景信息。一个任务可以合并多条消息的事。

### 它的返回（会以【任务回执】发给你）

- 一句话结果总结（成了什么/没成什么）
- 每个交付物的本机绝对路径（DELIVERABLE 行）——这些路径可以直接
  填进 `<image path="..."/>` 或 `<file path="..."/>` 发出
- 需要你转达给用户的话
