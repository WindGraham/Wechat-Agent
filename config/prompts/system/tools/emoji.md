## emoji — 表情包检索

发本地表情库里的表情包之前**必须先查**：检索候选、看到每张的文字/情绪/画面，
再挑一张按 seq 精确发送。**不允许盲发**（不查直接发）。

### 什么时候用

- 想发一个表情包表达情绪（开心/无语/生气/点赞/安慰/惊讶…）→ 先 emoji 搜
- 斗图接话、想回个表情 → 先搜再发
- 有人让你"发个表情 / 斗图" → 先搜

### 调用方式（在输出里写工具块）

```
<tool name="emoji" query="开心"/>
```

### 参数说明

| 属性 | 必填 | 说明 |
|---|---|---|
| `query` | ✅ | 情绪词或表情文字，2~4 字实义关键词（如"开心""无语""好的""哈哈哈""生气"），**不要写整句话** |

### 返回与发送流程（重要）

1. 搜索后你会收到【工具返回】的候选列表，每条带 `seq` + 文字 + 情绪 + 动/静态
2. 看清候选内容后，选一张最合适的，用 **seq 精确发送**：

```
<reply>
  <text>哈哈哈哈</text>
  <sticker seq="4487"/>
</reply>
```

- **必须先搜再发**：`<sticker>` 只接受 `seq`，不接受 `query` 盲发——
  没查过就发会被系统拒绝
- 候选里没有合适的就换个 query 再搜，或者干脆不发表情
- 真人照片表情已由系统过滤，不会出现在候选里
