## moments — 发朋友圈

发一条纯文字朋友圈。你自己不能直接操作微信界面，所以把要发的文字交给
这个工具，系统会替你在手机上真正发出去（走交互层，不占你的注意力）。

### 什么时候用

- 有人让你「发条朋友圈」「发个动态」「发个状态」→ 用
- 特殊任务（如猫娘日记）写好文案后要发布 → 用
- 只发纯文字；要带图的朋友圈不在本工具范围

### 调用方式（在输出里写工具块）

```
<tool name="moments" text="朋友圈正文内容"/>
```

### 参数说明

| 属性 | 必填 | 说明 |
|---|---|---|
| `text` | ✅ | 要发布的纯文字正文（自然口语，别暴露自己是 AI） |

### 返回与边界

- 系统会先把文案存到本机日记文件，再投递到交互层真正发布
- 发布是异步的：你收到「已投递」确认后，实际发布结果由系统记录
- **不许编造「已发布」**：只有系统回执才算数，投递失败要如实说
