# Android 端口实现规格

> 交互层 `ports/android/` 的实现依据。目标设备：root 安卓机，微信 8.0.76，
> 深色模式。端口内部允许硬编码标定；感知与操控的全部知识都在本文。

## 一、感知（截图 → 结构化状态）

**总路线**：`adb exec-out screencap` 内存截图（不落盘）→ 本地 OCR
（RapidOCR PP-OCR，GPU/CPU 均可）→ 区域切段解析。OCR 文字只"分配进段"，
不驱动分段——分段靠几何/颜色，文字允许错。

### 1. 页面判定

- 底部四 Tab 三重信号同位验证：图标模板 + 四短词 OCR + 绿色选中态
- 聊天页/首页/其他页由标题区+内容区特征区分；判定置信度不够必须降级
  为 unknown，禁止硬猜

### 2. 首页（会话列表）

- **行切段**：逐帧背景估计（直方图主峰）→ 细分割线 → 相邻分割线之间
  为一个会话条目；高度不足的残缺条目标 partial，不作候选
- **条目内分区**：头像列（左侧连通域）、名称区（行上部）、预览区（行下部）
- **未读标记**（条目级）：数字红圈（角标内数字 OCR）= unread N；
  纯色小圆点 = 免打扰红点 unread=-1；预览区红色"[有人@我]"= mention
  （颜色判定，不走 OCR）

### 3. 聊天页（头像顶切段法）

- **检测左右两列头像**（右列=自己），按顶边排序，相邻头像顶之间为一条消息
- **昵称条带**（仅群聊左侧消息）：x 起点=头像右缘+36px，y=头像顶附近
  限高条带（约 -10~+50），**横向不限宽**（长昵称不截断）；
  先验证灰色文字存在，再放大只走识别器读取
- **文字泡优先**：气泡颜色窗口 + 朝向头像侧尾巴凸角判定有泡 → text；
  无泡 → multimedia（打标，段条带裁图归档）
- 时间分割线/系统消息：居中灰小字单独成条
- **长文补读**：气泡高度暗示的行数 > OCR 已得行数时，按行投影找漏检行，
  裁剪后只走识别器补读

### 4. 已知设备坑（必须处理）

- 截图即读即删；内存截图优先
- 唤醒后停在 keyguard：WAKEUP 后必须 dismiss-keyguard
- 自动旋转会被系统打开：每个工作周期强制竖屏锁定
- 中文输入：`input text` 对中文不可用，用 ADBKeyBoard 广播输入
  （分块发送 + 随机停顿，防风控）；IME 锁定后输入栏有**两态**：
  聚焦时底部出现输入法细条，整条输入栏上移 ~125px——所有底部控件
  坐标必须按 聚焦/未聚焦 两态标定
- adb 可能同时存在 USB 和网络连接，命令必须带 `-s <serial>`

## 二、操控

- 一切点击/滑动走随机化封装：目标区域内高斯落点（±5~15px）、
  贝塞尔滑动轨迹、时长抖动、长按 600~900ms 随机
- 发送文字：聚焦输入框 → 清空 → 分块广播输入 → 绿色发送按钮掩膜校验
  → 点击 → 气泡验证（验证不到不重发，防重复刷屏）
- 发送图片：push 图片到相册目录 → 媒体扫描广播 → 加号面板 → 相册 →
  选第一张 → OCR 验证"发送(N)" → 发送（逐步 OCR 校验，不盲点）
- 发送文件：加号面板 → 文件 → 选择流程（同逐步校验）
- 引用回复：长按气泡 → 菜单 OCR 找"引用" → 输入 → 发送
- 进入会话：列表查找（当前屏 + 下翻至多 5 屏）→ 搜索兜底

## 三、端口接口实现

`observe()` 输出标准化 ScreenState（页面类型/标题/元素列表）；
`act()` 接受语义动作（tap(label)/long_press/swipe/type/back），
label→元素定位→随机化执行；`notify_events()` 轮询 dumpsys 通知
（含 @我 预判）。全部输出归一化，坐标不出端口。
