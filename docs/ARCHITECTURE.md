# Wechat-Agent 架构总览（v4）

> 本文是架构唯一总纲。三层详细职责见同目录三个分文档。

## 一、三层定义

```
三端微信（Android / Windows / macOS）
        ▲  │  原始屏幕/通知/消息
        │  ▼
┌─────────────────────────────────────┐
│ 交互层                               │
│ 把三端的消息转换成一样的接口，           │
│ 暴露给决策层；把决策层的回复动作         │
│ 翻译成对应端的具体操作                 │
└──────────────▲──────────────────────┘
               │ 统一消息接口（事件/动作）
               ▼
┌─────────────────────────────────────┐
│ 决策层（Agent 核心）                  │
│ 决定如何回复用户信息：回不回、回什么、   │
│ 什么时候把任务交给工具层               │
└──────────────▲──────────────────────┘
               │ 任务简报 / 结果回传
               ▼
┌─────────────────────────────────────┐
│ 工具层                               │
│ 不自研，直接接入现成的 CLI agent       │
│ 框架（首选 Kimi Code CLI），提供       │
│ 自由任务执行能力                       │
└─────────────────────────────────────┘
```

- **交互层**：三端适配器 + 运行循环组。对上只有一套接口——决策层不需要
  知道消息来自安卓截图还是 Windows UI 树，也不关心事件是轮询来的还是订阅来的。
- **决策层**：自研的 agent 核心。回复用户的决策权全部在这里。
- **工具层**：一个可用的 CLI agent 框架（Kimi Code CLI）。决策层把复杂任务
  交给它自由执行，拿回结果。

## 二、层间契约

| 接口 | 方向 | 内容 |
|---|---|---|
| `MessageEvent` | 交互层 → 决策层 | 归一化的新消息事件（会话/发送人/内容/类型/mention/媒体描述），三端同构 |
| `SessionContext` | 交互层 → 决策层 | 会话历史读取接口 |
| `ActionRequest` | 决策层 → 交互层 | 语义化动作（发文本/图片/引用/文件），决策层不指定坐标 |
| `TaskBrief` / `TaskResult` | 决策层 ⇄ 工具层 | 任务简报（目标/上下文/约束）与结构化结果 |

核心规则：**平台差异不许越过交互层上界；LLM 只在决策层出现；工具层对微信零感知。**

## 三、低耦合硬约束

三层之间的解耦是强制性的，不是倡导性的：

1. **只经契约通信**：层间只允许传递本文定义的契约对象（MessageEvent /
   ActionRequest / SessionContext / TaskBrief / TaskResult）。禁止共享可变
   全局状态，禁止把实现细节对象（截图、控件树、DB 连接）传出本层。
2. **依赖只朝接口**：决策层依赖交互层/工具层的**接口定义**，不 import 任何
   具体实现类；实现经依赖注入装配（入口组装处是唯一知道全貌的地方）。
3. **每层可独立替换**：换掉交互层的 Android 端口、换掉工具层的 CLI 框架、
   换掉决策层的 provider——任何一处替换都不许要求改另外两层的代码。
4. **每层可独立测试**：交互层用假决策层回放事件；决策层用假交互层/假工具层
   跑决策单测；工具层用脚本化任务验收。测试不许跨层连真机/真 LLM。
5. **异常边界**：任何一层的内部失败（OCR 崩了、CLI 超时、LLM 报错）只能
   以契约内的失败形式（`ok=False`/错误事件）传出，不许抛穿层界。

## 四、设计原则

1. 决策层是唯一的大脑：回复决策、人格、记忆调用、任务规划都归它。
2. 交互层只做"翻译"：消息进来翻成统一事件，动作出去翻成端上操作，附带
   行为伪装（随机化节奏）。它不理解业务。
3. 工具层买不造：成熟 CLI 框架直接接入，不把精力花在自研工具框架上。
4. 每端一份端口实现，允许硬编码标定；不做跨端自适应。
